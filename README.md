# 📚 Bookshelf – Landing Page

Landing page de uma plataforma fictícia de leitura online, desenvolvida com **HTML e CSS**, com foco em layout limpo, tipografia elegante e boa hierarquia visual.

## 🖥️ Tecnologias Utilizadas
- HTML5
- CSS3

## 🎯 Objetivo do Projeto
Praticar:
- Estruturação semântica em HTML
- Estilização com CSS
- Layout de landing page
- Organização visual e UX básico
